# README 更新审批自动化设计

日期：2026-10-02

## 目标

在仓库根目录新增 `AGENTS.md`，为单纯修改 `README.md` 的任务设置固定流程，减少重复确认。

## 规则

- 自动完成资料核对、README 编辑、格式检查、链接检查和差异审阅。
- 编辑和检查阶段不请求用户批准。
- 准备提交时展示变更摘要与检查结果，并且只请求一次批准。
- 用户批准后，自动执行暂存、提交和推送，不再重复请求业务确认。
- 如果变更涉及 README 之外的代码、凭证、实验数据或破坏性操作，则不适用该授权。
- 仓库规则不能覆盖平台强制的权限或安全审批；平台要求确认时仍按要求处理。

## 验收条件

- 文件名使用 Codex 识别的 `AGENTS.md`。
- 规则简短、明确，且只作用于 README 更新任务。
- 明确唯一的用户审批点和审批后的自动步骤。
