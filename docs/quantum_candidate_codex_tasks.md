# 本地 Codex 实现交接：机器候选量子搜索

先读 [设计文档](quantum_candidate_design.md) 与 [demo README](../code/candidate_quantum_demo/README.md)。本文是未来实现任务，不表示已经完成。

## 任务目标

保留经典候选生成和图评价接口，将量子变量从局部交换位改为机器候选标签；实现环/路径投影相位、保持编码合法性的混合器、约束指导联合跃迁，验证数百比特资源目标。先完成小实例门级正确性，再扩大实例与资源估算。

必须区分：模型正确性、池内最优、原问题全局最优、有限时间采样成功、量子优势。不要将实验假设改写成已证定理。

## P0：数据契约与经典接口适配

建议新增独立包，不破坏现有可复现实验。

- `CandidatePool`：instance_id、pool_version、每机器有序 candidate_id 列表、operation_id 排列、来源、内容哈希。
- `Witness`：kind=cycle/path、原始节点序列、每机器先后关系、路径长度、见证哈希；集合掩码是绑定 pool_version 的派生数据。
- `JointTransition`：机器集合、左右候选编号、权重、依据的见证编号；禁止依赖最优答案标签。
- `QuantumRequest`：池版本、见证集合、T 模式、混合器、规范化、预算、随机种子。
- `QuantumResult`：读数/频数、非法编码比例、逻辑/物理资源、编译选项、时间与训练开销。

候选池更新后必须从原始先后关系重新编译所有集合掩码，不能沿用旧 candidate_id 语义。所有索引约定为零基，工序 ID 与机器 ID 分开。

验收：错误候选、重复工序、缺失工序、池版本错配明确拒绝；CPU 解码与独立排程检验一致。CUDA 工作仅接到既定批处理接口，先保留 CPU 后备。

## P1：小实例投影相位门

1. 实现 one-hot 编码与合法初态；可选二进制标签编码对照。
2. 将每机器 allowed 集合计算成标志位；同机多先后关系先取交集。
3. 实现环合取相位、路径合取与 `T < length` 比较相位；反计算后辅助位回零。
4. 不使用完整 costs 数组或任意全空间 diagonal 合成；直接从 Witness 生成门。
5. 去除恒真机器条件，跳过恒假见证；不以此删除仍然有效的全局语义。

验收：对小实例每个合法基态及随机叠加态，与 demo 能量相位逐振幅比较（允许整体相位）；检查 T=L-1、T=L、T=L+1；检查辅助位反计算。非法编码处理有明确记录。

## P2：混合器与联合跃迁

- 实现连通单机器 XY 基线，并给出工期寄存器的混合策略。
- 实现 2–4 台机器的受限联合转移，保持每机 one-hot；支持集合外的寄存器作用恒等。
- 联合候选由当前见证提议，经典侧不提供已枚举最优组合。
- 保留基础跃迁连通性；联合项在终点权重为零。
- 对非对易乘积公式记录顺序、步数和误差，不能把奇偶重排宣称为无损等价。

验收：小状态空间验证厄米性、编码保持、支持范围、连通性及门级演化；固定范数或如实记录能量尺度，不能以增大整体驱动制造速度优势。

## P3：量子采样—经典验证—见证反馈闭环

```text
初始化可行排程、候选池、独立全局 LB 和 UB
重复直到时间/资源预算耗尽：
    将现有 Witness 编译成量子主问题
    采样多个组合（附 T，或使用固定 T 模式）
    批量解码完整 JSP
    可行结果更新 UB；违约结果生成有效环/路径见证
    去重见证，提出联合跃迁；必要时更新候选池并重编译掩码
    记录数据传输、评价、编译、训练、shots 与时间
```

量子低能读数不能被当作主问题精确下界。固定 T 下采样失败不能证明不可行。若精确经典 master 仅作小规模核对，应单独计时、单独标记，不参与量子优势计分。

验收：随时可中止并输出经过验证的最好排程；主问题语义、池内下界和原 JSP 下界不混用；外层保持历史最好工期不劣，但不声称量子能量单调下降。

## P4：资源预算与 50×20 接入

先编译每机 8 候选（160 数据位），再按门数与深度评估是否增加到 16 候选。报告 T 位、辅助位峰值、反计算、路由、双比特门、深度、测量与噪声。不要只报告数据位。

生产路径禁止构造 `product(*all_candidates)` 的完整成本表、长度为全组合数的数组或稠密哈密顿矩阵。对参考模拟器设置明确维度上限。数百位电路先做资源编译，不尝试完整经典状态向量模拟。

限制活跃约束集会损失单轮完整性。可保留全部原始见证于经典存储，选择部分用于电路，同时每轮继续完整图验证；被省略约束不能当作仍已量子执行。

## P5：实验与优势评估

至少比较：普通混合、联合混合、相同信息的经典联合移动、经典整数 master。必要时增加模拟量子退火或张量网络基线。两类口径均报告：相同评价次数、相同端到端时间。

指标：目标工期成功率/时间、可行率、独立全局 gap、分布、候选更新次数、约束数/支持规模、训练与编译成本、总资源。多实例多种子报告；保存无改进和退化结果。

对极小实例可计算完整谱，检查能隙、参数与步长收敛；网格谱不构成连续能隙证书。纠缠熵可作为机理指标，不能代替性能证据。

## 明确的停止/拒绝结论条件

- 联合混合器持续不优于相同信息的经典联合移动：报告负结果，重新审查动力学假设。
- 见证数或联合项深度超预算：报告具体瓶颈，不把成本隐藏为免费 oracle。
- 候选池遗漏最优：报告池内界限，不能归咎量子采样。
- 未获得全局证书：返回最好已知可行工期及有效 gap，不返回“全局最优”。
