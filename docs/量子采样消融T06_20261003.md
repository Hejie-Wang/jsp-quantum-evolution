# 量子分布的独立贡献与关联强度消融（T06，Issue #19）

日期：2026-10-03。基线：T04（PR #40）+ T05（PR #32）堆叠分支。依据 [PR #18 拆解文档](量子计算能否改善JSP问题的求解+子问题拆解TODO.md) 的 T06 工作包。执行：glm bot（jsp-agent-glm），开发位置：`improvement-glm`，分支 `glm/t06-sampling-ablation`。审查：deepseek。

**性质声明：全部为经典模拟（CompactSimulator 精确子空间模拟 / 独立均匀采样 / 经典退火），无 QPU、无硬件宣称。每个窗口的全部臂获得相同池、见证、目标 T 与 incumbent 信息；唯一变化的是提议分布。精确枚举只在离线打分层出现，任何臂都不读取。**

## 范围与方法

`sampling_ablation.py` 在 T04 冻结的 D2-dev 窗口上做固定窗口组件对照。窗口选择：critical_path 策略下有改进的快照（正样本）+ 迭代 5000 无改进快照（负对照）；本次 pilot 取 13 个有改进窗口 + 5 个负对照。种子 0–2 记为开发、3–4 记为确认（全部超参数在实验前冻结：shots=64 主批、256 副批、训练预算 12 次参数评价、2 层，无任何窗口上调参）。

七个臂（shots=64，原始频数保留、去重不丢弃）：

| 臂 | 分布 | 训练 |
|---|---|---|
| uniform | 独立逐机均匀标签（T00 独立对照） | 无 |
| sa_energy | 同一代理能量上的经典退火链（64 次能量评价，访问态记为原始样本） | 无 |
| xy | 见证相位 + XY 混洗，均匀合法初态 | 12 次精确期望参数评价 |
| xy_joint | 相位 + XY + 见证派生联合跃迁 | 同上 |
| xy_joint_warm | 同 xy_joint，采样时初态改为 incumbent 基态（训练管线不变） | 同上 |
| mixers_only | **相位消融**：见证集置空（能量全零），仅 XY+联合混洗 | 同上 |
| xy_joint_shots | 同 xy_joint，训练用 64 shots 多项式抽样的能量估计（768 shots 全部计入） | 12 次 × 64 shots |

单变量消融：相位（xy_joint vs mixers_only）、联合门（xy_joint vs xy）、热启动（xy_joint vs xy_joint_warm）、训练目标（xy_joint vs xy_joint_shots）。打分缓存逐窗口共享（唯一组合至多 729 个，每组合一次独立图检查器评价），臂间零重复评价。

## 结果

### 主对照（13 个有改进窗口，shots=64，配对 bootstrap 10k）

| 臂 | p_imp 均值 | 配对差 vs uniform（95% CI） | 差值门槛（CI>0） | 比率门槛（≥1.10 且 CI>1） |
|---|---|---|---|---|
| uniform（基线） | 0.0036 | — | — | — |
| **sa_energy** | **0.0373** | **+0.0337（+0.0024, +0.0793）** | **通过** | 未通过（比率 CI 不稳） |
| xy | 0.0024 | −0.0012（−0.0060, +0.0036） | 未通过 | 未通过 |
| xy_joint | 0.0036 | +0.0000（−0.0036, +0.0036） | 未通过 | 未通过 |
| xy_joint_warm | 0.0096 | +0.0060（−0.0048, +0.0180） | 未通过 | 未通过 |
| mixers_only | 0.0072 | +0.0036（−0.0024, +0.0108） | 未通过 | 未通过 |
| xy_joint_shots | 0.0048 | +0.0012（−0.0024, +0.0048） | 未通过 | 未通过 |

**负对照（5 窗口）**：全部臂 p_imp=0.0——无改进窗口上没有任何臂浪费调用质量（拒绝无效调用的纪律通过）。

**副批（256 shots，uniform vs xy_joint）**：0.0024 vs 0.0018——提高 shots 不改变结论。

**开发/确认半区**：sa_energy 开发半区 0.0692、**确认半区 0.0000**（xy_joint 0.0067/0.0000）。SA 的优势集中在开发半区，在确认半区未被复现——主表的差值门槛通过主要被开发半区驱动，按预注册的分半纪律如实报告。

### 消融读数（数值方向，均不显著）

1. **相位**：去掉见证相位（mixers_only 0.0072）反而数值高于 xy_joint（0.0036）——在此预算下见证相位**没有可测的分布收益**。
2. **联合跃迁**：xy_joint（0.0036）≈ xy（0.0024）——联合门无可见贡献。
3. **热启动**：warm 0.0096 vs 0.0036（2.7×，CI 含 0）——方向为正但不显著；完整热启动训练管线留待 T07 参数复用。
4. **训练目标**：精确期望 vs 有限 shots（0.0036 vs 0.0048）——同层。

### 机制解释（与 T04 交付闭环）

有改进窗口的精确 ρ 均值仅 **0.0032**（每窗 729 组合中约 2 个改进组合），且 T04 已证明这些改进 90% 以上是单机切换。这意味着：任何接近均匀的分布（所有量子臂在 2 层/12 次评价预算下都接近均匀）的 p_imp 必然贴近 ρ≈0.003 的基率；SA 能把采样质量集中到低能量（少违约）状态，才获得 ~10× 基率的 p_imp。**瓶颈不是量子门的种类或初态，而是"稀疏改进集合 + 小训练预算"下变分分布无法重塑到可辨别水平。**

## 门槛判定与结论

按 PR #18 §5 T06 推进条款：

1. **相同图评价预算下的有效采样效率**：量子各臂 vs uniform **全部未通过**共同门槛（差值与比率双口径）。
2. **计入训练成本后的端到端收益**：训练本身成本极小（精确期望 12 次评价 ≈ 10 ms；shots 版 768 shots），但既然分布级收益未通过，端到端无从谈起——**未通过**。
3. **对照臂结论**：同能量经典 SA 是唯一通过差值门槛的臂（vs uniform），但其优势未在确认半区复现。

**结论：两项门槛均失败 → 按 T06 条款停止扩大量子窗口，输出负结果。** 在当前候选质量（稀疏改进集合）与训练预算下，相位/联合/热启动/训练目标四个模块没有任何一个表现出可测的采样收益；同代理的经典退火是更强的消费者（但优势不稳定）。

## 对下游的交付

1. **T07**：量子调用模块应作为"长期无效模块"的首要禁用/降频候选（T07 验收条款正是"允许禁用长期无效模块并如实报告调用占比"）；本 PR 的 `run_window` 臂接口即 T07 调用策略模拟的组件级依据。
2. **T08**：完整算法的经典默认提议路径由此获得组件级证据；量子接口保留但默认关闭，重新启用需要 T04 门槛（候选质量修复）先行。
3. **T09**：本 pilot 的负结果与 T09 的模拟机制门槛互不冲突——T09 测"硬件是否保留作用"，T06 测"作用是否有求解价值"；两者都偏向否定才是停止的充分依据。

## 边界与未完成项

1. **窗口改进密度过低**：D2-dev 无高密度档（ρ 最大 0.206，均值 0.003）——§3.1 的 DQ 分层预选（低/中/高三档各 2）在当前数据下只能取低/中档；若 T04 的候选生成改进落地（产生高密度窗口），本消融需重跑后才允许重新评估量子模块。
2. **确认半区样本量小**（6 窗口）：分半数字只作方向参考，正式确认需种子 100–119 的 D2 确认集。
3. **训练预算为预注册下限**：12 次参数评价/2 层是 §3.2 主预算；更大预算属于"扩大量子实验"，按推进条款在负结果下不予投入。
4. **热启动消融范围**：只改采样初态、训练管线不变（CompactSimulator 的 train/probabilities 路径为均匀初态固定）；完整热启动训练属 T07 参数复用场景。
