# 量子分布的独立贡献与关联强度消融（T06，Issue #19）——pilot，含负结果

日期：2026-10-03。基线：main `daa727d`（T03 PR #31 合并后）；T05（PR #32）、T09（PR #34）、T11（PR #33）为本轮并行交付。依据 [PR #18 拆解文档](量子计算能否改善JSP问题的求解+子问题拆解TODO.md) 的 T06 工作包。执行：deepseek bot（jsp-agent-deepseek），开发位置：`improvement-deepseek` 独立 clone（#28 v2），分支 `deepseek/t06-sampling-ablation`。审查：glm（分工见 Issue #19）。

**性质声明：**

1. 本报告是 **pilot**：窗口来自 D0 冻结层（D2 未落地，属 T04），**不是确认集结果**；所有比率都标为探索性。
2. **没有量子硬件、没有后端、没有真机作业**；所有「量子」臂都是本地理想模拟（compact 精确模拟 + Aer 采样）。
3. **结论是负结果并如实保留**：在预注册预算下，变分相位/XY/联合臂的改进命中概率**不高于**独立均匀采样；报告不把它写成「未完成」，也不事后换指标。
4. 所有臂共享同一池、同一冻结见证集、同一固定 T 与同一初态信息；**没有任何臂读取精确枚举答案**，精确枚举只作为离线参照单列。

## 2. 结果

### 2.1 改进命中概率 `p_hit`（合法 ∧ 无环 ∧ C<u0 的概率质量）

| 窗口 | uniform | SA（每次运行） | xy/exact | xy/shots | xy+joint/exact | xy+joint/shots |
|---|---|---|---|---|---|---|
| 3×3 seed2 | 0.1481 | 1.00 | 0.1377 | 0.1160 | 0.1301 | 0.1301 |
| 3×3 seed7 | 0.0370 | 1.00 | 0.0316 | 0.0316 | 0.0207 | 0.0218 |
| 4×3 seed0 | 0.0370 | 1.00 | 0.0195 | 0.0195 | 0.0238 | 0.0238 |
| 4×3 seed3 | 0.0370 | 0.40 | 0.0334 | 0.0337 | 0.0302 | 0.0298 |
| 4×3 seed7 | 0.0370 | 1.00 | 0.0359 | 0.0359 | 0.0320 | 0.0396 |
| 3×3 seed0（负对照） | 0 | 0 | 0 | 0 | 0 | 0 |
| 4×3 seed1（负对照） | 0 | 0 | 0 | 0 | 0 | 0 |

宏平均与配对比较（对 uniform 的比率，窗口重采样 bootstrap 10,000 次，**探索性**）：

| 臂 | 宏平均 `p_hit` | 配对比率均值 | 95% CI | 判读 |
|---|---|---|---|---|
| uniform（主基线） | 0.0423 | 1.00 | — | — |
| xy/exact | 0.0369 | 0.836 | [0.677, 0.939] | **劣于**基线（CI 上端 < 1） |
| xy/shots | 0.0338 | 0.808 | [0.658, 0.922] | **劣于**基线 |
| xy+joint/exact | 0.0338 | 0.752 | [0.636, 0.860] | **劣于**基线 |
| xy+joint/shots | 0.0350 | 0.797 | [0.654, 0.945] | **劣于**基线 |
| SA（同一 `H_T`，每次运行） | 0.6286 | 19.71 | [11.61, 27.0] | 见 §2.3：**单位图评价成本并不占优** |

**结论（T06 门槛不通过）**：在相同池、相同见证、相同信息与预注册预算下，四个变分臂的 `p_hit` **都低于**独立均匀采样（比率 0.75–0.84，CI 上端全部 < 1），且这还没有计入它们额外的训练成本（12 次参数评价、shots 训练耗时 2–7 s/窗口 vs uniform 的 0 s）。按 T06 条款「两者均失败时停止扩大量子窗口，输出负结果」，本轮**不扩大**量子窗口。

### 2.2 归因：代理能量的平坦区正好是改进所在处

| 窗口 | 改进组合数 | 其中 `H_T=0` | 零能集合大小 | 「完美集中在零能集合」的 `p_hit` 上限 | 变分臂实测 `p_hit` |
|---|---|---|---|---|---|
| 3×3 seed2 | 4 | 4 | 7 | **0.571** | 0.130–0.138 |
| 3×3 seed7 | 1 | 1 | 2 | **0.500** | 0.021–0.032 |
| 4×3 seed0 | 1 | 1 | 3 | **0.333** | 0.020–0.024 |
| 4×3 seed3 | 1 | 1 | 3 | **0.333** | 0.030–0.034 |
| 4×3 seed7 | 1 | 1 | 10 | **0.100** | 0.032–0.040 |

三点可复核事实：

1. **所有改进组合都落在 `H_T=0` 内**（零能集合是改进集的超集，零能集合只占池的 7%–37%），说明见证能量作为**可行性代理**是「不漏」的；
2. 但在零能集合**内部**，`H_T ≡ 0` **没有任何梯度**，训练目标无法区分「可行但不变好」与「改进」——因此理想机制下的上限（0.10–0.571）与实测（0.02–0.14）之间的差距，本质上是**代理目标不携带 makespan 信息**，而不是电路或采样器的问题（与 T03 的 Kendall τ 随规模衰减、T05 的「零能 ≠ 可行/改进」互相印证）；
3. 12 次参数评价的预注册预算也远不足以把分布压到零能集合上（实测期望能量从均匀的 ~2.2 只降到 1.59–3.08）。

### 2.3 成本口径：把「每次运行」与「每次图评价」分开

| 臂 | 单位成本 | 单位成本下的改进效率 |
|---|---|---|
| uniform | 1 次图评价/样本 | **6.75–27 次图评价/命中**（=1/ρ） |
| SA（`H_T` 直接评价） | 201 次见证评价 + 186–478 次图评价/命中 | **186–478 次图评价/命中**，是 uniform 的 7–70 倍 |
| 变分臂 | 12 次参数评价 + 训练 shots（0 或 12×64=768）+ 每次采样 1 次图评价 | 12–48 次图评价/命中（含训练则更高，且命中质量低于 uniform） |

即：**SA 的「每次运行成功率」看起来最高（0.4–1.0），但按图评价计费它比均匀采样更贵**；变分臂则在任何口径下都不占优。这与仓库既有结论（T01：85% 窗口池内无改进；T03：代理排序能力有限）一致。

## 3. 与验收条款对照

| PR #18 T06 验收条款 | 本次证据 |
|---|---|
| 所有模式获得同一池、见证、动作与初态信息 | 单一 `window_setup` 冻结对象被所有臂复用；测试覆盖 |
| 至少比较 独立均匀 / 经典联合搜索 / 同能量 SA / 相位+XY / 相位+XY+联合跃迁 | uniform、SA（同 `H_T`）、xy、xy+joint 已实现；**经典联合搜索臂用 `search_loop.classical_joint_search` 的既有实现**（见 §5 边界第 3 条说明的比较口径） |
| 分别消融相位、联合门、热启动、代理权重与训练目标 | 相位+XY 与相位+XY+联合两臂对照；初态固定为均匀合法（未做热启动臂） |
| 保留单机 XY 通道 | `xy` 臂即「相位 + 单机 XY」 |
| 联合动作基于多见证冲突修复，不能按标签编号邻近选端点 | 复用 `search_loop.propose_joint_actions`（按见证支撑度排序、整组离开允许集合） |
| CVaR/成功率训练必须保留原始频数 | 本轮目标为期望 `H_T`（未用 CVaR）；shots 档保留采样频数 |
| 全状态精确期望训练与有限 shots 训练分列 | 每个变分臂都跑 `exact` 与 `shots` 两档并分别报告（含 `training_shots`） |
| 输出每窗口有效概率、可行率、重复率、参数评价数、训练时间、图评价数和总时间 | 全部字段在 JSON 中逐臂输出（`p_hit`、`feasible_rate`、`unique_choices`、`parameter_evaluations`、`training_seconds`、`graph_evaluations_per_hit`、`sampled_p_hit`、`shot_estimates`） |
| 对 `p_imp=0` 的窗口报告无效调用成本，不能排除 | 两个负对照窗口保留在结果里，全部臂为 0，成本照记 |
| 推进门槛：同图评价预算下有效采样效率达门槛；计入训练后仍达门槛才称端到端收益 | **两档均未达**：配对比率 0.75–0.84，CI 上端 < 1 → 按条款**停止扩大量子窗口，输出负结果** |
| 理想模拟收益不等于真实量子速度优势 | 本报告不作任何速度优势主张 |

## 4. 边界与未完成项

1. **D2 未落地**：本报告的窗口为 D0 冻结层的 pilot，用于机制诊断；T04 交付 D2 后必须按确认集口径重跑（T06 的确认要求是 D2 训练/确认窗口按轨迹隔离）。
2. **池规模小**（∏K_m = 27）：`p_hit` 的分辨率与 bootstrap 的样本量都有限，跨窗口比率只作探索性判读。
3. **经典联合搜索臂**在代码中通过仓库既有的 `classical_joint_search` 接口存在（同一见证能量、同一联合动作、零违约触发图评价），但本轮**未纳入统一预算表**（其内层步数与时间预算与原实现绑定），因此 §2.3 的成本对照只覆盖 uniform / SA / 变分三族；把经典联合搜索臂纳入同一「图评价预算」是 D2 重跑时必须补齐的一项。
4. **未做热启动臂与代理权重消融**（T06 列举项中的后半部分）；本轮聚焦「相位 / 联合门的独立贡献」。
5. **训练预算极小**（12 次评价）是预注册的值；本报告不主张「变分方法在此问题上无效」，只主张「在该预算与该校验口径下无收益」。
