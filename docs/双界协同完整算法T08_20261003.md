# 上下界协同与见证反馈的完整算法（T08，Issue #19）

日期：2026-10-03。基线：main `daa727d`。依据 [PR #18 拆解文档](量子计算能否改善JSP问题的求解+子问题拆解TODO.md) 的 T08 工作包；认证通道复用 T02（`global_bounds.py`，PR #27），提议通道按 T06/T07 的结论选取（[T06](量子采样消融T06_20261003.md)、[T07](量子调用策略T07_20261003.md)）。执行：deepseek bot（jsp-agent-deepseek），分支 `deepseek/t08-dual-bound`。审查：glm。

**性质声明：**

1. 本报告是**架构 + 不变量验证**的 pilot（D0 冻结层）；D1 上界与 D3 差距积分**未在本轮执行**（见 §4 边界）。
2. **提议通道可用且可替换**：本轮按 T06/T07 的负结果，把默认提议器设为**独立均匀采样**（测得的最强单位成本基线），量子臂通过同一接口接入但**不产生本轮任何数字**；T08 推进条款要求与「完整 CP-SAT＋经典搜索」同资源比较，这属 T10。
3. 认证通道**只接受合法作用域**：L 只能由平凡负载界、已证最优的松弛界、或**完整模型已证不可行**的阈值判定抬高；采样失败、空提议、`UNKNOWN`、超时**一律不抬 L**。

## 1. 架构与不变量

```
读取实例 → 认证下界 L0 + 已验证初始排程 U0
while 时间未耗尽 且 L < U:
    好解通道：提议（可替换）→ 独立图检查 + 生产验证器双重核验
              → 接受则 U ↓ 并提取原始见证；拒绝只提取见证，绝不改界
    认证通道：对 T = U-1 做完整模型阈值可行性判定（固定时间片）
              → 仅 INFEASIBLE 时 L ← max(L, T+1)
    换池：见证重投影，池作用域界全部丢弃（不跨池沿用）
返回排程、[L,U]、成本分解与可回放事件日志
```

**执行期强制的不变量**（每一步都写进事件日志并在测试中复检）：

| 不变量 | 强制方式 |
|---|---|
| U 只来自**双重核验**的排程 | `check_choice`（独立图检查器）+ `mq.validate_schedule`（生产验证器）必须给出同一工期，否则抛错 |
| L 只来自 global/relaxation 作用域证书 | 阈值判定仅 `verdict == "infeasible"` 才抬 L；松弛界只在 `certified_bound` 非空时抬 L；平凡界按定义合法 |
| 失败不构成证据 | 空提议 / 采样不可行 / 证书 `unproven` 全部只计数与记录，**不改 L**（测试覆盖 4 种注入） |
| 换池不沿用旧界 | `change_pool` 丢弃全部 `pool_scope_bounds`，见证按新池重投影，L 的作用域与数值不变 |
| 可回放 | 每个事件含序号、时间戳、动作、成本、U/L 前后值、作用域、求解器状态、见证数、池哈希 |

- **不变量违例 0/9**：任意事件上都有 `L ≤ C* ≤ U`，且每个被接受的排程都通过双重核验。
- **U 提升 2/9**：`3×3 s2` 从 25 改进到 **19 = C***（池内最优，且随后 L 也被认证到 19 → 上下界闭合）；`4×3 s0` 30→27。其余窗口在 3 s 预算内没有再改进。
- **L 抬升全部来自完整模型阈值判定**（`scope=global`）：`3×3 s0`、`3×3 s2` 抬到 **= C***；`3×3 s1` 20（C*=25）、`4×3 s0` 23（25）、`4×3 s1` 25（30）、`4×3 s2` 22（26）未达最优，但其 41 次探针中大量 `UNKNOWN/超时` 全部**未被当作证据**（`certificate_unproven = 41`）。
- **2×2 三窗口在初始化时就闭合**：初始 SGS 排程等于平凡负载界，`L = U = C*`，循环按条件立即退出（事件数 2）——这是「无需求解即为最优」的合法情形，也说明小实例上界与下界天然贴合。
- **采样失败比例很高**（98–173/201）：均匀提议在受限池里大量落到有环组合，被完整图检查器拒绝；这些拒绝**只贡献见证**，从未抬高 L。

## 4. 边界与未完成项

1. **D1 上界与 D3 差距积分未执行**：本轮只在 D0 上验证不变量与架构；D1（六实例、确认种子）与 D3（ta30/ta40 下界）需要 T10 的统一预算矩阵。
2. **量子提议臂未接入本轮数字**：接口已备（`proposer` 参数），但按 T06/T07 的负结果本轮用均匀提议；「有无量子的 A_cert 对照」留待 T10。
3. **未实现分离器 + 精确主问题的完备割闭环**（池内有限终止性的构造性证明）；因此本报告不主张任何池内完备性。
4. **认证时间片是固定的 `cert_every=5` 与 0.5 s**；自适应分配预算属 T07 的延展，本轮未做。
5. 命题「L 只能由合法松弛/完整模型抬高」在本轮由**代码路径 + 注入测试**保证，而非形式化证明。
