## 2. 可逆 oracle 的构造与资源（D0）

### 2.1 作用域与构造

`reversible_oracle.py` 实现 `O_T: |a⟩|b⟩|0⟩ ↦ |a⟩|b ⊕ 1[G(a) 无环且 C(a) ≤ T]⟩|0⟩`，作用域限定为 **D0 的 2×2 家族**（每台机器恰好两条工序：`2 jobs × 2 machines`）。此时每台机器只有两种机器顺序，可用**一个二元方向位** `d_m` 表示「哪条工序先做」，于是：

- 方向位由 one-hot 数据位异或得到（合法 one-hot 子空间上精确，与生产门层同一约定）；
- 谓词是**仅关于 k 个方向位**的真值表（k = 机器数 = 2，共 4 项），每项用独立图检查器 `check_choice` 求值得到「无环 ∧ C ≤ T」；
- **不预计算 `2^(数据位)` 规模的组合成本表**，也不读任何精确答案文件；
- 电路为 compute / copy / uncompute：对每个满足的方向模式施加多控 X 到共享 minterm 辅助位，一次 CX 写入答案位，再逐门反向反计算，使所有工作位归零。

### 2.2 验证结果（D0 2×2 × 种子 0–9，T = u0 与 u0−1 两档，共 20 个窗口-目标对）

| 检查项 | 结果 |
|---|---|
| 合法基态逐态状态矢量核对（每对 4 个全部输入） | 答案位与经典判定不一致 **0** |
| 工作位反计算归零 | 脏态 **0**；`max_probability_error`（与理想概率分布的最大偏差）= **0.0** |
| 逻辑资源（代表性） | 8 线（4 数据 + 2 方向 + 1 minterm + 1 答案）；7 逻辑门（5 CX + 2 MCX），逻辑深度 5 |
| 转译资源（`cx/u/rz/sx/x`，O1） | 17 CX，深度 22，门数 33 |
| 资源函数（本作用域） | 线数 `= ΣK_m + k + 2`；门数 `= 2k + 1 + 2·Σ_{满足模式}(1 + 该模式的 0 控制数)`；反计算与计算同量 |

### 2.3 条件性盈亏平衡与失败区间

测量得到本窗口的经典「均匀抽样 + 图评价」成本为 **c_classical ≈ 1.01e−5 s/样本**（2000 次重复的均值），`p` 为状态准备命中满足目标状态的概率（均匀取合法 one-hot）：

`T_Q ≈ g·τ/√p + T_fixed`，`T_C ≈ c_classical/p`，其中 `g` 为计入门数、`τ` 为单门时间。

| 场景 | τ（单门） | T_Q（g=7, p=0.25） | T_C | 允许的固定开销上界 |
|---|---|---|---|---|
| 容错门级速度 | 1 ns | 1.4e−8 s | 3.63e−5 s | 3.63e−5 s |
| 近邻门级速度 | 100 ns | 1.4e−6 s | 3.63e−5 s | 3.49e−5 s |
| 慢门/含测量重载 | 1 µs | 1.4e−5 s | 3.63e−5 s | 2.23e−5 s |

- **盈亏平衡单门时间** `τ* = c_classical/(g·√p) ≈ 2.9e−6 s`：**只有单门时间低于约 2.9 µs 且固定开销（制备、测量、编排、重试）低于表中的上界，条件性查询优势才成立**；否则不成立。
- **失败区间（必须与上表同时读）**：
  1. `T_fixed` 取 0 是本表的乐观假设；真实 QPU 单次任务延迟通常在 1e−4–1e−2 s 量级，**这会把上表全部场景翻转为负结论**。因此本报告只给「固定开销上界」，不宣布优势。
  2. **p = 0 档（T = u0−1，10/20 个窗口-目标对）没有盈亏平衡**：满足集合为空，振幅放大无对象。该档的不可行性由**结构表本身**（2^k 项完整枚举）作为经典证书给出——这正是 T11 要求的「p=0 需另设完整算法或经典证书」，本作用域下等于经典完整枚举。
  3. 本作用域只有 `p ∈ {0, 0.25}` 两个取值，**没有中间区间**：D0 2×2 的最优组合唯一，`p` 无法更细地刻画收益曲线；D2 规模的外推只是模型，未构造电路。

## 4. 边界与未完成项

1. **oracle 只覆盖每机两条工序的实例**（2 jobs × 2 machines）。3×3/4×3（每机 3 条工序，需要 `log2(6)≈2.6` 位表示机器顺序）与 D1/D2 规模的结构化环检测/最长路可逆构造**未实现**；因此 §2.3 的 D2 外推只能是公式层面的模型，不能当实测。
2. **未做谱隙/能标归一化测量**（不属本轮）；未做真机执行（T09，且真机未获授权）。
3. 摊销比较的对象是**均匀抽样过程**，不是 CP-SAT；本报告不主张相对最佳经典求解器的普遍优势。
4. 与文献的**端到端同预算对照**未做（rank 编码 vs 整机候选编码、紧凑编码 vs 我们的相位编码）；这是 T11 之后若要形成论文级新颖性主张必须补的实验。
5. `p` 的定义依赖「状态准备方式」；本报告用均匀合法 one-hot 与位串均匀两种口径中的前者，后者只在代码里可切换（`success_probability(..., preparation=...)`），未在结果表中并列。
