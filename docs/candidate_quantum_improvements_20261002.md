**P1：复用辅助位，替换联合门的稠密综合**

每条见证执行“计算标志 → 相位 → 反计算”，随后复用同一工作寄存器，不能按见证数量累加分配。20 台机器、每机 8 候选、44 条见证时，当前固定工期电路声明 1172 位；按现有工作区布局复用后约 183 位，另计多控门分解和设备映射成本。已有 206 位报告只编译了 2 条见证。

联合门目标为 `exp[-iθ(|a><b|+|b><a|)]`，仅旋转两种指定局部候选组合。对 r 台机器各取左右两个 one-hot 位，在这 2r 位上采用下列精确构造，替换 `UnitaryGate(dense_matrix)`：

```text
选择 a、b 不同的一位作为目标 t
对其他不同位 j 施加 CX(t, j)，使变换后的 a、b 仅在 t 上不同
对非目标位中共同为 0 的位施加 X，使控制条件全为 1
施加以其余 2r-1 位控制的 Rx(2θ)，目标为 t
逆序撤销 X 和 CX
```

示例中每台机器左右候选必须不同，其他数据位不参与该门。小规模稠密矩阵只保留为测试参照。复用工作区后，处理提前跳过的路径分支也必须确保辅助位归零。

验收：r=2/3/4 时逐矩阵验证等价性、合法编码保持和非目标状态不变；在相同编译设置下比较 CX 数、深度和辅助位峰值。必须记录纳入/省略的见证数量，不以逻辑门数替代编译后成本。

**P2：接通固定工期的量子优化闭环**

当前 `run_demo_sampling` 仅“均匀叠加 → 相位 → 测量”，测量概率不会因该相位改变。先实现固定 T 的多层电路：

`合法初态 → [见证相位 → 单机 XY → 多机联合跃迁] × p → 测量`。

固定 T 时取 `H_T = Σ_C w_C Π_C + Σ_{P:L(P)>T} w_P Π_P`，所有权重为正。参数优化在同一轮冻结的见证集合上进行；限制层数、参数评价次数及 shots，记录训练成本。

```text
保留已验证初始排程，T = best_makespan - 1
在总预算内重复：
    由当前见证提出 2–4 台机器的联合动作
    构造并调参多层电路，采样候选组合
    去重组合，调用现有完整图评价
    可行且更优：保存排程并更新 T
    不可行或超 T：提取、去重并加入有效环/路径见证
    记录概率、评价次数、工期和全部时间成本
```

联合动作优先覆盖同一环或关键路径涉及的机器，考察必须协同替换才能解除冲突的动作；保留连通的单机 XY 基线，不能直接按前几台机器、首个候选机械构造，也不能利用已知最优标签设计动作。

验收：先在总模拟比特数符合现有预算的小池上验证；相位后接混合器能够在非退化小例中改变采样分布，所有输出排程通过独立验证。外层历史最好工期不劣；采样失败不证明不可行，量子能量不承诺单调下降。大规模只做资源编译，禁止完整状态向量扩容。
